TRAE Loop Privacy Policy

Last updated: August 27, 2026

This Privacy Policy explains how the TRAE Loop Chrome extension ("TRAE Loop", "we", or "the extension") handles information when you use its visual development, task review, and live preview features.

1. Information We Process

Depending on the features you choose to use, TRAE Loop may process:

  • Account information: information returned through Feishu OAuth, such as your name, avatar, user identifier, and authentication session.
  • Website and element information: the current page URL, page title, and DOM, selector, text, attributes, and visual style information for elements that you explicitly select.
  • Task content: task descriptions, feedback, selected element details, task status, conversation history, and preview configuration needed to create and manage development tasks.
  • Screenshots and recordings: screenshots, interaction records, console or network error summaries, and screen recordings only when you explicitly initiate the relevant capture or recording feature.
  • Technical environment information: task-specific environment identifiers and environment-related request headers used for acceptance and live preview sessions.

2. How We Use Information

We use this information only to provide TRAE Loop functionality:

  • Authenticate users and maintain their extension session.
  • Create, continue, display, and review development tasks.
  • Identify selected webpage elements for requested code changes.
  • Diagnose user-reported issues when capture features are used.
  • Open and maintain tab-scoped acceptance and live preview environments.
  • Display task progress, conversations, and results.

We do not sell personal information, use it for advertising, or use it for purposes unrelated to the extension's single purpose.

3. When Information Is Sent

Information is sent only when required by a feature you use. Task content and selected element data may be sent to the TRAE Loop backend and authorized remote development services to perform the requested task. Feishu processes authentication and may receive task notifications or attachments when those features are used.

Screen recordings and screenshots are not collected automatically. They are uploaded only after a user initiates the applicable feature and submits the task.

4. Browser Permissions

  • Host access allows the extension to operate on pages where the user enables it and selects elements.
  • Declarative network request access adds tab-scoped environment headers for acceptance and live preview.
  • Web request access observes environment-related headers in read-only mode so the interface can reflect the active environment.
  • Identity access supports Feishu OAuth authentication.
  • Offscreen access supports optional user-initiated screen recording under Manifest V3.
  • The side panel permission provides the primary extension interface.

5. Storage and Retention

Authentication and interface settings may be stored in Chrome local or session storage. Authentication data is removed when you sign out or when it expires. Task records and user-submitted attachments may be retained by the TRAE Loop service for as long as needed to provide task history, review, troubleshooting, and organizational compliance.

6. Security

We use reasonable technical and organizational safeguards to protect information in transit and at rest. No method of transmission or storage is completely secure, so absolute security cannot be guaranteed.

7. User Choices

You control when TRAE Loop is enabled, which elements are selected, and whether screenshots or recordings are captured. You may sign out to remove the locally stored authentication session and may disable or uninstall the extension at any time.

8. Children's Privacy

TRAE Loop is a developer productivity tool and is not directed to children under 13.

9. Changes to This Policy

We may update this policy when the extension's features or data practices change. The latest version and its effective date will be published on this page.

10. Contact

For privacy questions or data requests, contact the publisher using the verified contact email shown on the TRAE Loop Chrome Web Store listing.
